Campus scoping at the database layer

Row-level filtering through Prisma middleware with a role registry that tags certain roles as campusOptional. A Principal at one campus physically cannot read another campus's data, even with hand-crafted API requests.

02

Field-level encryption with a startup canary

AES-256-GCM at the column level with an enc: ciphertext marker. On every API boot, a sentinel row is encrypted and decrypted — if the key has changed, the server refuses to boot rather than corrupting data silently.

03

Tamper-evident audit log

Every entry hashes the previous entry's SHA-256. A daily verification job walks the chain end to end. The chain re-anchors on retention pruning so it stays verifiable across years of history.

04

The biometric pivot

April 2026: scrapped a flaky ZKTeco / ZLink Cloud / ADMS integration after weeks of webhook signature failures. Replaced with manual clock-in plus end-of-day xlsx import. Reliability beat cleverness; payroll became correct.

async function verifyEncryptionKey() {
  const canary = await db.systemCanary.findFirst()
  if (!canary) return seedCanary()

  try {
    const decrypted = decrypt(canary.payload)
    if (decrypted !== KNOWN_PLAINTEXT) throw new Error('mismatch')
  } catch (e) {
    logger.fatal({ err: e }, 'PII_ENCRYPTION_KEY appears rotated.')
    process.exit(1)  // loud failure beats silent corruption
  }
}
